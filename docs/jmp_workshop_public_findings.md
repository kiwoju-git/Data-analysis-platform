# Workshop Review: Public Summary

Supplied training slides, instructions and saved journals were reviewed locally.
They are not licensed public regression fixtures. Original slides, tables,
measurements, screenshots, paths and derived sample-specific comparison numbers
are excluded from the repository; local evidence is retained separately.

The review separated published workflow descriptions, saved example snapshots,
independent synthetic calculations and actual application execution. Saved
starting values are not necessarily fitted parameters. A measured response is
not a prediction, and a displayed interval cannot be converted into SD without
its confidence level and latent/predictive definition.

## Implementation Consequences

- Fitting needs bounded multistart diagnostics and best-evaluation retention;
  optimizer success alone does not establish a good likelihood optimum.
- Desirability curve policy must be saved explicitly. The existing DS policy
  and an explicitly selected peak-one Gaussian target are different policies.
- Candidate tables, ordered manual selection and source-locked profilers need
  persistent fitted-state and revision contracts, not a larger review cache.
- Augmentation criteria must remain distinct from existing greedy MC EI.
- Nominal/ordinal and mixture examples cannot be reproduced by arbitrary numeric
  coding or by dropping unsupported factors. No full JMP parity is claimed.

Synthetic independent Cholesky, quadrature, derivative and lifecycle tests are
the redistributable evidence. Current gate documents record actual executions;
this summary is not a claim that every remaining feature is implemented.
